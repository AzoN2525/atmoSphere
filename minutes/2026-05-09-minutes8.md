## Discussões e Decisões

### 1. Ponto 1: Distribuição de tarefas

**Discussão:**  
A equipa reuniu-se para definir e distribuir as tarefas pendentes relacionadas com o desenvolvimento do frontend. Foram analisadas as funcionalidades principais a implementar, tendo em conta a estrutura do projeto definida na reunião anterior.

Foram discutidas as views necessárias, os componentes reutilizáveis e a integração futura com os endpoints da API REST já desenvolvidos.

**Decisão:**  
As tarefas foram distribuídas pelos elementos da equipa, garantindo que cada membro ficou responsável por uma parte específica do desenvolvimento frontend.

---

### 2. Ponto 2: Desenvolvimento das tarefas individualmente

**Discussão:**  
Após a distribuição das tarefas, cada elemento iniciou o desenvolvimento da funcionalidade atribuída. O trabalho foi realizado individualmente, mantendo a comunicação entre a equipa para esclarecer dúvidas e garantir coerência entre os diferentes módulos.

**Decisão:**  
Ficou acordado que cada membro continuará a desenvolver a sua tarefa individualmente, sendo posteriormente feita uma revisão conjunta para integração e validação do trabalho realizado.
